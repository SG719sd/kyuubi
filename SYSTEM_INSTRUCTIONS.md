# Istruzioni Progetto per AI Studio

1. **Framework**: Questo progetto è sviluppato esclusivamente con **Next.js** e **npm**.
2. **Nessun Bundler Esterno**: NON tentare di creare o modificare file `vite.config.js`, `vite.config.ts` o di installare Vite.
3. **Modifiche al Codice**: Limitati a modificare i file all'interno delle cartelle `src/app/`, `src/components/`, `src/lib/`, `src/server/`, `src/types/`, `src/utils/` o `public/`.
4. **Dipendenze**: Se sono necessarie nuove librerie, aggiungile direttamente al file `package.json` sotto `dependencies` senza eseguire comandi da terminale incompatibili.
